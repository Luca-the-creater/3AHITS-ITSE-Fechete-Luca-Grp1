## wc genauer angeschaut

Mit `wc` kann man je nach Option Verschiedenes zählen lassen. Ich hab das Ganze an der Datei `klassenkassa.csv` ausprobiert.

**`-m` zählt die Zeichen.** Das `\n` am Zeilenende wird dabei mitgezählt, deshalb kommt man auf einen Wert höher als gedacht.
```sh
wc -m klassenkassa.csv
# 4377 klassenkassa.csv
```

**`-l` zählt die Zeilen.**
```sh
wc -l klassenkassa.csv
# 146 klassenkassa.csv
```

**`-L` gibt die Länge der längsten Zeile aus.**
```sh
wc -L klassenkassa.csv
# 36 klassenkassa.csv
```

**`-w` zählt die Wörter.**
```sh
wc -w klassenkassa.csv
# 146 klassenkassa.csv
```

## Aufgabe: Was macht diese Zeile?

Wir sollten rausfinden, was hier passiert:
```sh
echo eins zwei drei | wc - klassenkassa.csv
```

Die Ausgabe war:
```sh
1       3      15 -
146     146    4384 klassenkassa.csv
147     149    4399 total
```

Was ich erkennen kann:

Das `-` sagt `wc`, dass es den Text aus der Pipe (von `echo`) lesen soll. `wc` zählt darum zwei Quellen gleichzeitig.

- **Erste Zeile (`-`):** Das ist der Text `eins zwei drei`. Ergibt 1 Zeile, 3 Wörter und 15 Zeichen (die 15 kommen durch das mitgezählte `\n`).
- **Zweite Zeile:** Das Gleiche, aber für die Datei `klassenkassa.csv`.
- **Dritte Zeile (`total`):** Hier werden die Werte aus beiden Quellen einfach zusammengezählt.

> Reihenfolge bei `wc` ist standardmäßig: Zeilen, Wörter, Zeichen.
