### Übung (curl und Notenmanagement II) ###

Was ich erkennen kann:

Wenn ich in der API Dokumentation schaue, kann ich mit curl zum Beispiel meine eigenen Noten mit 
```sh
GET /api/Schueler/{MatrikelNr}/Noten
```
abrufen oder eine bestimmte Leistungsfeststellung mit 
```sh
GET /api/LFs/{LF_ID}.
```
Man braucht aber immer einen Access-Token den man zuerst mit 
```sh
POST /api/Token
```
holt und dann bei jedem Request im Header mitschickt.
