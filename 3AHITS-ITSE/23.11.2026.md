### Bridged Mode aktivieren

Kali:

    1. Gehen sie ihn den Manager 
    2. Drücken sie auf Virtuell Maschin Settings
    3. Danach auf Network Adapter und schalten sie Bridged an 
    4. Gehen sie auf Configure Adapters und wählen sie da intel aus

Meta:

    1. Gehen sie ihn den Manager 
    2. Drücken sie auf Virtuell Maschin Settings
    3. Danach auf Network Adapter und schalten sie Bridged an 
    4. Gehen sie auf Configure Adapters und wählen sie da intel aus
    5. Machen sie das bei beinen Network Adapter
